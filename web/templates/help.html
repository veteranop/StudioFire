StudioFire — Operator's Manual

A plain-English guide for running {{ station }}. No IT knowledge needed. If you can read this page, you can run the station.

Start here — the one thing to remember. StudioFire is built so the music never stops. If the screen looks wrong, the music is almost certainly still playing. Nothing you can click on these pages will make {{ station }} go silent — the worst case is you change what's playing next. When in doubt, look at the green ON AIR light on the On Air screen. Green means you're fine.

The On Air screen

This is the page you'll leave open. It answers one question: what is playing, and is the station OK?

What you seeWhat it means
ON AIR (green)The automation is running and feeding the transmitter. All good.
OFF AIRThe engine isn't feeding audio. See If something looks wrong.
Program Output meters (L / R)The sound level leaving the studio. If the bars stop moving, no audio is playing.
Now playing + Next upThe current track and what follows.
Studio health pillGreen = healthy. Click it for the detail behind it.

Safe buttons on this screen: Shuffle reshuffles the current list, and Restart restarts the StudioFire services if you're asked to. Neither can leave the station silent — if audio ever needs a moment, filler plays automatically.

Playing music

A playlist is a list of songs. You build it once, save it, and play it whenever you want. To put music on air:

  1. Open Playlists in the top bar.
  2. Click the playlist you want, then Play — it goes on air and starts with the first song.
  3. Use Shuffle to reorder it into a random mix if you don't want the same order every time.
  4. Add songs by searching the library and clicking Add; drag to reorder; Save when done.

Folders that rotate. A playlist can hold a whole folder instead of single songs. Choose Rotate through folder to play every file once before any repeats (fair for underwriters), or Newest from folder to always take the latest file.

Spots, IDs & underwriters

"Spots" are everything that isn't music: legal station IDs, underwriting credits, PSAs and promos. They're scheduled as rules — "play this folder every hour," "play this underwriter's credit twice a day."

  • Set up or edit spot rules on the Schedule page.
  • Underwriting is never called advertising — {{ station }} is non-commercial. The wording matters; leave it as written.
  • Legal IDs must air every hour. The Reports page has a Legal ID report that flags any hour that missed one.

The schedule

The Schedule page is where time-based things live: shows that start at a set hour, and spot rules that fire on a clock. Set the day and time, choose what plays, and save. StudioFire handles the timing.

Reports — what aired

The Reports page is your proof of what actually played. Pick a date range and run it. It can export a CSV you can open in Excel or hand to an underwriter. This is the record you'd use to show that a credit, ID or PSA really aired.

Settings

Everything you configure lives under Settings. The common items:

SettingWhat it does
Users & passwordsAdd operators, change roles (admin vs operator), reset passwords.
FoldersWhere each kind of audio lives (shows, IDs, PSAs, jingles, underwriters).
Clock12-hour or 24-hour display.
Software updatesInstalls new StudioFire versions. See the note below.
Backup / restoreSave a copy of your setup, or restore one.
About updates. Install update only installs the same version series you're already on (1.x). A whole new major version (like 2.0) is treated separately and can never install by accident — it needs an admin to type the version number in on purpose. So it's safe to click the normal update button.

Duplicate cleanup

Over time the library collects the same song more than once. Settings → Duplicate cleanup finds them, shows them side by side, and moves the copies you don't want into a _Duplicates folder — never deletes them. Songs used by a playlist, show or spot are protected and left alone.

If something looks wrong

Breathe. StudioFire is designed to fail safely. Here's what to do:

What you seeWhat to do
"EMERGENCY FILLER IS ON AIR" (yellow banner) The normal playlist couldn't continue, so StudioFire switched to safe music automatically. You are still on air. Fix the playlist when you can — there's no rush.
"AUDIO ENGINE NOT RESPONDING" (red banner) The web page lost contact with the audio engine. The music may still be playing. Try Restart; if it persists, call support.
Meters flat, no sound, OFF AIR Check the on-air PC is powered and the studio gear is on, then call support. Don't unplug anything while it's running.
Page won't loadWait a few seconds and reload. Visit the on-air PC and check its screen.

Who to call

{{ station }} is supported by VeteranOp. If anything looks wrong, call or message your support contact — include the time it started and a photo of the screen if you can. Never improvise on the on-air machine.
